HOMELAB – Infraestrutura Conteinerizada & Microsserviços

Projeto principal · 2024 – Presente
Desafio: Criar um ambiente corporativo reproduzido em casa, com múltiplos serviços isolados, gerenciáveis e acessíveis remotamente — sem depender de cloud pública.
Solução: Servidor dedicado (Dell OptiPlex 3000, Windows Server 2025 + Ubuntu) gerenciando 15+ containers Docker com roteamento por Nginx Proxy Manager, isolamento de rede, certificados SSL automatizados e painel de status em tempo real via Portainer e Uptime Kuma.
Linux (Ubuntu) Docker Nginx Proxy Manager Portainer Uptime Kuma Homepage n8n

Monitoramento & Observabilidade Proativa

Automação de Deploy e Provisionamento Windows 11

PowerShell · Corporativo · 2026
Desafio: Reduzir drasticamente o tempo de configuração de estações de trabalho corporativas, eliminando tarefas repetitivas de pós-instalação.
Solução: Kit completo com mídia bootável USB (UEFI+BIOS), autounattend.xml, drivers Intel RST VMD e 11 scripts PowerShell automatizando: criação de usuários, naming, IPv6, Office ProPlus 2021, Chrome, Firefox, Java, WinRAR e Adobe Reader.
PowerShell Windows 11 Shell Scripting Autounattend Office 2021

Edge Security & Infraestrutura Web
